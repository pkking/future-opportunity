## Objective

Reduce the remaining manual orchestration between "choose market days" and the
already-verified read-only campaign planner.

Target flow:

```text
explicit acquisition manifest
  -> Funding UTC date range
  -> explicit Cash cases
  -> existing reusable preparation workflows
  -> one acquisition Actions run containing all compact artifacts
  -> read-only planner scans that exact run
  -> deterministic <=31-item promotion wave manifests
```

The acquisition workflow MUST NOT promote, create corpus branches, create PRs,
or merge anything.

## Design decisions

- Funding acquisition is an explicit inclusive UTC date range, max 31 days.
- Cash acquisition is an explicit list of cases:
  `entry_at, exit_at, future_id, expiry_at`.
- Cash discovery remains a separate evidence tool. This workflow never converts
  a discovery result into an implicit strategy holding period.
- Funding and Cash preparation reuse the existing workflow_call contracts; no
  duplicate preparation implementation is introduced.
- All compact artifacts generated by one acquisition campaign share the caller
  workflow run ID, allowing the read-only planner to inventory one exact run.
- Planner output remains review-only evidence. It does not count as pinned
  readiness until a later explicit promotion PR is merged.
